SOLAR BAY — an original open-world crime game built for make.fun's "Make GTA 6" bounty ($1,666 in USDC). A sun-soaked bay city to explore on foot and by car: steal cars, outrun police at 5 wanted levels, run 3 story missions for Mara, fight the Vex crew, with traffic, pedestrians, a day/night cycle, procedural sound, a HUD with minimap, and a local save. No Rockstar / GTA names, characters, art or music — everything here is original.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or serve `game/` with any static server and open `game/index.html`.

## Controls

WASD / arrows — move or drive · E — steal / exit car · Space/F — punch · Click — shoot · M — mission brief · P — pause · R — restart
